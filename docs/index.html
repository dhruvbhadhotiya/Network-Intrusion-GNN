Why do GNNs underperform baselines on the test set? GNNs learn rich node-neighbourhood embeddings during training. The test set, however, contains only flows between unknown IP pairs that all map to a single UNK node (index 50). With no meaningful neighbourhood to aggregate over, the GNN's structural advantage is eliminated — only edge features carry signal. Classical baselines use edge features directly and therefore generalise much better to the shifted distribution.
